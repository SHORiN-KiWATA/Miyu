## 修复
- 终端里她的回复不再被拆成一行一段（「问我的模型的话」「那还是不说，」「这」各占一行、中间空一行，连行内代码都被从中间劈开）。根因是有些供应商在每个正文分片上都附带一个空的 `reasoning_content: ""`，Miyu 把空串也当成一段推理的开始，于是每个分片前都插了一次「推理分段开始」，终端一收到这个信号就把正在打的正文行截断。现在空推理字段按「没有」处理（Chat、Anthropic、Responses、Claude Code 四条协议同修），终端侧也改成只有真要写思考摘要时才断行。
- 手机上 WebUI 的回车改成换行了，发送用右下角的按钮（或 Ctrl/Cmd+Enter）。软键盘上没有 Shift+Enter，以前回车即发送，多行消息根本打不出来。桌面端不变。
- 手机上数据统计页的环形图不再挤在表格左边把表格压成一条：窄屏下改成环形图在上、表格整行在下，断点和手机布局其它部分对齐（836px）。
- 「回到底部」按钮不再压在后台任务条上。它离底部的距离是按输入区高度写死的一个数，后台任务条出现或增行、软键盘顶起视口时输入区变高，那个数却没人更新，按钮就留在原地盖住任务条，手机上一点就误触。现在直接盯输入区的尺寸变化，谁改都跟上。
- 打开页面、刷新、切换会话时，上下文条显示的窗口大小现在是**这个会话**当前模型的，不再是全局默认模型的。会话钉了模型池时，回合和压缩两条路都按那个池算，唯独快照接口漏了，于是要跑完一轮才被纠正；打开一次设置页也会把它改回全局值，同修。
- 终端 REPL 里 `/models` 的结果行（「当前会话模型: …」「当前会话已恢复跟随全局激活模型池」）不再被画到输入框那一行上或者整个被盖掉。选择器和结果行是直接往终端打的，而输入区还挂在屏上、也不知道多了几行；现在先收起输入区、打完再按真实光标位置挂回去。
- WebUI 里在会话内换模型（仅本会话）后，上下文条的窗口大小立刻按新模型更新，不用再等跑完一轮或刷新页面。
- WebUI 整段重建时间线（后台任务完成、目标续轮这类由 daemon 自己发起的回合落盘时）不再把「自动跟随到底部」关掉：重建会让浏览器把滚动位置钳到顶再跳回底，中间那次归零以前被当成你在往上翻。这条按代码推断修复，本机用无头浏览器三种时序都没复现出原始现象，实际效果请以真机为准。
