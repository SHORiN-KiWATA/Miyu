---

- 开发模式（`miyu dev`）瘦身，让模型少受无关提示词干扰。本机实测一轮的固定开销从约 3900 token 降到约 2950（−24%）：
  - **不再有记忆功能**。开发模式不再记日记、不再自动联想，也没有 `remember_fact` / `recall_memories` 了。以前它会把上一个开发会话的闲聊记录当成「近期发生的事情」灌进新会话——写代码用不上这个，反而把闲聊的语气带了回来。普通模式的记忆一切照旧；关掉之前存下的开发模式记忆还在库里，用 `/reset-all-memory`（选开发模式）随时清得掉。
  - **不再有技能**。开发模式没有创作技能的工具，却看得见一份技能清单——而且那份清单是**普通人格的**技能（抖音下载、显卡直通之类），对写代码毫无用处。需要给它技能的话，在 `config/dev-prompt.md` 里写一行目录路径，让它自己去读。
  - **按需加载工具只在用得上时才出现**。工具目录是「全部展开」模式时 `load_tools` 谁也不会去调，这种会话里不再挂着它；历史上真调用过的会话仍旧保留，不会撞上未知工具。
  - 逐出上下文检索（`search_evicted_context`）随记忆一起退场。注意：开发模式的 `miyu pop` 弹出去的对话不再进归档库，也就找不回来了。
  - 用 Claude Code 订阅当供应商时，桥给 claude 那边挂的 Miyu 工具从 11 件减到 6 件；`edit` 也交还给 Claude 自己的 Edit/Write——两者管的是同一件事，而中转这条线上 Miyu 的 `edit` 连修改前后的对比都显示不出来。
