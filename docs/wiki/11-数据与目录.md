# 11 · 数据与目录

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

## 1. 根目录：`~/.miyu`

默认一切都在 `~/.miyu`（`MIYU_HOME` 可改）。目录权限都是 0700（只有你自己能进）。

```text
~/.miyu/
├── config/
│   ├── config.jsonc              主配置（JSONC，允许注释）
│   ├── dev-prompt.md             开发模式提示词
│   └── shell/                    bash/zsh hook 文件
├── data/
│   ├── prompts/                  人格 .md、system-prompt.md
│   ├── identities/               用户身份 .md
│   ├── persona-avatars/          人格头像
│   ├── skills/                   用户技能
│   ├── scripts/                  用户脚本
│   ├── memes/                    用户表情库（可能）
│   ├── pictures/
│   │   ├── web-images/           搜图保存
│   │   └── generated-images/     生图保存
│   ├── documents/
│   │   └── deep-thinking/        深度研究报告
│   ├── kb/                       用户知识库
│   ├── artifacts/<session_id>/   WebUI Artifact
│   ├── shared/<share_id>/        WebUI 分享文件托管区（快照模式与页面上传）
│   └── platforms/onebot/message_history/history.sqlite3  群聊消息历史
├── cache/
│   ├── logs/                     miyu.*.log、cache-usage.*.jsonl、requests-*.jsonl、alarm.log
│   ├── jobs/<id>.log             后台任务日志
│   ├── clipboard_images/         剪贴板图片
│   ├── platform_files/qq/        QQ 文件下载
│   └── aur-review/ aur-install/  AUR 审查/安装缓存

    ├── conversation.db           会话/记忆/平台状态 SQLite（WAL）

    ├── usage.json                累计用量
    ├── usage-history.jsonl       逐条用量明细
    ├── thinking-variants.json    思考档位选择
```

实际路径可用 `miyu paths` 打印。注意：资源迁移后部分目录（skills/scripts/prompts/identities）从旧 `config/` 挪到 `data/`；迁移期间存在兼容窗口。

## 2. 系统级目录（打包安装）

| 路径 | 内容 | 缺失时的表现 |
|---|---|---|
| `/usr/share/miyu/fonts/` | Noto CJK + Color Emoji | QQ 长回复转图退化为纯文本 |
| `/usr/share/miyu/memes/miyu/` | 内置表情 | 默认人格无内置表情 |
| `/usr/share/miyu/default-kb/` | 默认知识库 | 默认知识库为空 |
| `/usr/share/miyu/scripts/` | 系统脚本 | 无内置脚本 |

## 3. 数据库要点

- 主库 `conversation.db` 使用 WAL、busy_timeout 5s、外键开启；迁移 24 个版本，每个迁移在 immediate 事务里做并跑 FK check。
- **不要**在 daemon 运行时直接删/改 DB；先 `miyu daemon stop`。
- 旧版本迁移到 `~/.miyu` 时：旧 XDG 目录里的 config/data/cache/state 会被搬过来；`Documents/Miyu` → `data/documents`；`Pictures/miyu`、`Pictures/Miyu` → `data/pictures`。
- 迁移前会两遍预检，失败零写入；符号链接、跨文件系统等危险情况会拒绝或丢弃缓存。

## 4. 运行期目录

- IPC socket：`$XDG_RUNTIME_DIR/miyu/core.sock`；没有 XDG_RUNTIME_DIR 时回退 `state/miyu`。
- 锁文件：`core.lock`（daemon/web 单实例）、`starter.lock`（启动互斥）。
- 权限：socket 目录 0700、密码文件 0600。

## 5. 日志

| 文件/流 | 内容 |
|---|---|
| `cache/logs/miyu.*.log` | 按天滚动 8 份；默认 ERROR，QQ 日志 INFO |
| `cache/logs/daemon.log` | daemon 启动 banner/panic 等非结构化输出 |
| `cache/logs/cache-usage.<date>.jsonl` | 每请求 token 绝对值（默认开，保留 14 天） |
| `cache/logs/requests-<date>.jsonl` | 完整请求体（默认关，`MIYU_LOG_REQUESTS=1`） |
| `cache/logs/alarm.log` | 闹钟 worker 日志 |

`--debug` 把主日志提到 DEBUG。`daemon logs request` 是进程内存开关，不落配置。
