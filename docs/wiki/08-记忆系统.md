# 08 · 记忆系统

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

Miyu 会“记日记”，还会把日记整理成长期记忆和知识点。这里解释它到底怎么记、怎么忘、怎么清。

## 1. 三类记忆

| 类型 | 存什么 | 生命周期 |
|---|---|---|
| 短期日记（short_term） | 每个成功完成的对话轮次，立刻写一条 | 默认保留 14 天，被有效联想召回会续期 |
| 长期日记（long_term） | 从短期日记整理出的“值得回溯的经历” | 随时间衰减为“已遗忘”，不物理删除 |
| 知识点（fact） | 长期有效的事实，例如“用户用 N 卡” | 同上，可显式搜索找回 |

## 2. 自动整理（MemoryOrganizer）

- 同一人格累计 **14 条**未整理短期日记后，独立后台线程开始整理，不阻塞回复。
- 整理器用 LLM 提炼：长期知识点 + 有回溯价值的长期经历。
- 成功整理的短期日记进入保留期；召回达到 **3 次**会立即触发长期化整理。
- 尚未整理的原文超期后**不再自动联想，但不会丢**，后台仍可继续整理；整理成功后才物理清理。
- 整理失败会按 2s、4s、8s……指数退避重试（封顶 300s）；每次唤醒最多整理 4 批、每批最多 20 条。

## 3. 联想检索

每轮对话前，Miyu 会拿当前原文做一次记忆联想：

- 同时检索短期日记、长期日记、知识点。
- 用 `jieba-rs` 中文分词 + FST 紧凑词典做关键词匹配；语义检索开启时（默认开，内置本地模型）再算一路向量相似度，两路排名做 RRF 融合。向量存在记忆库的 `memory_embeddings` 表里，每轮最多补 32 条、其余由后台任务慢慢补齐；语义那一路失败就只剩关键词，联想不会因此停摆。
- 联想结果只追加在**本轮消息尾部**，并作为“化石”永久回放——这是缓存设计的刻意选择（见 10 章）。

## 4. 遗忘

- 长期知识点和长期日记按半衰期（默认 7 天）衰减，强度低于阈值后标记“已遗忘”。
- 遗忘不是删除：显式 `miyu memory search --forgotten` 仍能找到。
- 成功联想会刷新保留时间，相当于“复习”。

## 5. 访问权限（隐私边界）

记忆存储全局按人格隔离，但读取分三类 visibility：

| visibility | 谁能进模型上下文/工具 |
|---|---|
| public | 当前人格所有场景 |
| principal | 只给同一发送者主体（例如 QQ 群里某个用户） |
| privileged | 只给 Owner/管理员等特权上下文 |

这样 QQ 群里的 A 不会读到只有 B 相关的记忆。

## 6. 命令

```bash
miyu memory stats
miyu memory search "关键词" -l 5
miyu memory search "关键词" --forgotten
miyu memory remember "用户喜欢用 kitty 终端" -s manual
miyu memory reset                  # 清空当前人格记忆
miyu memory reset --session <ID>   # 只清某个会话记下的记忆
miyu memory reset --include-skills # 连用户技能一起清
```

REPL 与 QQ 都有 `/reset-memory`（只清本会话记下的）与 `/reset-all-memory`（清人格全部）。

## 7. reset 的三种语义（别混）

| 命令/操作 | 清什么 |
|---|---|
| `/clear` | 只清屏幕，不碰任何数据 |
| `/reset`（终端/WebUI） | 只清当前会话上下文 |
| `/reset all`（终端/WebUI 特殊路径） | 清当前人格全部记忆（短期+长期+知识点+修订+待整理） |
| `/reset-memory` | 清**本会话**记下的记忆，保留会话历史 |
| `/reset-all-memory` | 清当前人格的全部记忆，保留会话历史 |
| `/wipe` | 全抹：会话历史、记忆、群聊上下文及其产物 |

重置保护：主体记忆在一个事务里清理；即使后台整理器正在写旧结果，也会因为数据库身份/记忆代数变化被拒绝，不会“清完又复活”。

## 8. 配置项

`plugins.memory` 常用默认：

| 项 | 默认 | 说明 |
|---|---|---|
| enabled | true | 总开关 |
| auto_diary | true | 自动写短期日记 |
| auto_fact | true | 自动整理知识点 |
| diary_batch | 14 | 攒多少条触发整理 |
| short_diary_retention | 14 天 | 短期原文保留 |
| diary_promotion_recalls | 3 | 召回几次立即长期化 |
| forgetting_enabled | true | 遗忘开关 |
| half_life | 7 天 | 衰减半衰期 |
| min_strength | 0.15 | 低于它视为遗忘 |
| association | true | 联想开关 |
| evicted_context | true | 可搜索被逐出上下文的历史（search_evicted_context） |
| auto_skill_enabled | false | 从经验自动提炼技能（实验） |
