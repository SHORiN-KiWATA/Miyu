# 16 · 安全与隐私

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

Miyu 会读文件、跑命令、访问网络、接入 QQ。它的安全设计原则是：**权限由代码判定，危险操作默认谨慎，数据尽量只留在本机。**

## 1. 你的密钥和隐私数据在哪里

- 配置：`~/.miyu/config/config.jsonc`（目录权限 0700）。
- API key 支持 `$env:VAR` 形式，建议敏感 key 放环境变量而不是明文配置。
- Web 密码存在 `state/web-passwords/`（0600），daemon 启动状态文件**不含明文密码**。
- 数据库、日志、缓存都在 `~/.miyu`（权限 0700）。
- 导出归档是**明文 tar.gz**，默认带密钥；权限 0600。发出去前请用 `--no-secrets`。

## 2. LLM 数据边界

- 你的对话、记忆、文件内容会发送给你配置的模型供应商。Miyu 无法把数据“只留在本地”运行大模型。
- 默认 opencode 公共模型意味着内容经过公共网关；注重隐私请配置自己的 API。
- `cache-usage` 日志默认只记 token 数字，**不记提示词正文**。
- `MIYU_LOG_REQUESTS=1` 或 `daemon logs request` 会记录完整请求体，排查完记得关。
- QQ 群聊上下文、消息历史会进入模型上下文，所以不要用 Miyu 的 QQ 群收发秘密信息。

## 3. 命令与文件操作护栏

| 操作 | 护栏 |
|---|---|
| 执行命令 | 1–120 秒超时；独立进程组可整组杀；输出 8 MiB 上限；`tools.command_deny` 黑名单 |
| 删除文件 | 默认走回收站 `trash_path`；拒绝 `/`、家目录、工作区根、Trash 自身等 15 类危险目标；提示词要求先列清单确认 |
| 安装软件 | 提示词要求先确认；AUR 安装必须 PKGBUILD 审查通过且用户确认 |
| 文件读取 | 50 KiB / 2000 行 / 单行 2000 字符；平台文件 128 KiB；二进制拒绝 |
| 搜索根目录 | 排除 /dev /proc /sys /run /tmp 和大量缓存目录 |
| 写文件 | UTF-8 校验；原子写入 |
| Artifact | 目录 0700/文件 0600；拒绝 symlink 与路径逃逸 |
| 搜图下载 | 禁代理、防 SSRF、DNS 固定、图片魔数/尺寸/解码校验 |
| 网页抓取 | 5 MiB 上限 |
| 诊断 check_issue | 只读取证；$HOME 脱敏、IP/MAC 打码、journal 限量 |

## 4. 权限模型

### 终端/WebUI（Owner）

- 本地用户视为 Owner：完整工具、完整记忆权限。
- WebUI 密码保护可选；没有密码时**不要**把 `0.0.0.0` 暴露到不可信网络。公网用 HTTPS 或 `--bind 127.0.0.1`。
- 登录限流：同 IP 60 秒内失败 5 次锁 429。
- 多用户：成员账号凭管理员的一次性邀请码注册（邀请码只存 sha256，8 位、默认 7 天）；密码 PBKDF2-HMAC-SHA256 存库；会话、事件流、用量按账号隔离，`/api/dash/*`、`/api/config`、供应商、语音、QQ 等管理接口成员一律 403。成员对话时的记忆按 principal（`web:<账号 id>`）隔离，与 QQ 群成员同一套规则。成员与管理员跑在同一台机器、同一套工具面上，没有沙盒。

### QQ 平台

- 只信 QQ 号，不信昵称；身份映射会拦截冒名者。
- 管理员：静态 `admin_users` 或动态授权，免限流，能用宿主工具和管理命令。
- 群聊非管理员**永远无法**使用发消息/@人等宿主工具。
- 私聊白名单才能开非管理员宿主工具。
- 游客有限流：私聊 2/600s，群聊 2/600s。
- 平台工具集是受限注册表：没有 shell/本地文件/记忆/知识库，避免“QQ 一句话删你电脑文件”。

## 5. 提示词安全

- 默认人格有内容红线：不碰宗教政治时局、黄赌毒、带坏未成年人话题、恋爱模拟等。
- QQ 有 moderation 审核：默认开启，命中严重度 ≥7 强制触发并附审核提示；Base64 藏内容也会被解码检查。
- QQ 历史是“不可信数据”，real_context 和 judge 的提示词明确声明不可信输入、工具返回数据需判断。
- 所有用户昵称/正文做控制字符清理，防终端转义注入。

## 6. 传输与本地 IPC

- OneBot token 用 SHA-256 摘要比较；WS 帧 16 MiB 上限。
- 平台附件用 5 分钟随机 token 租约 URL，最大 50 MiB、最多 128 个。
- IPC socket 在 0700 目录；帧上限 24 MiB；管理命令需要 AdminResult。
- WebUI 永远要登录：首次访问用内置账号（用户名 `miyu`，密码 `miyu`）登录并创建管理员账号，建完号内置账号即失效；之后只认账号（密码 PBKDF2 存库），别人凭一次性邀请码注册。启动参数里没有任何密码。
- 成员沙盒（Landlock）：成员回合里 `run_command`、后台任务、脚本工具起的进程只能写自己家里的 `home/<用户名>/workspace/`、`/tmp` 与脚本缓存目录，整机其余只读；规则在子进程 exec 前装好、随 exec 继承，子进程再起的进程一样受限。内核没有 Landlock（5.13 以下或被禁）时成员的命令直接被拒，不会裸奔。管理员、终端、QQ 等平台回合不套沙盒。只管文件系统，不管网络。

## 7. 你可以做的加固

- 配置自己的 API，并定期轮换 key。
- 用 `$env:` 引用 key。
- WebUI 加密码；只本机用就 `--bind 127.0.0.1`。
- QQ token 设长随机值；开启白名单；非必要不开非白名单游客。
- 备份用 `miyu export --no-secrets` 再传。
- 定期看 `miyu daemon logs request`（临时）或用量明细，确认没有异常请求。
