# 17 · 常见问题

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

## 安装与启动

### `miyu` 命令不存在 / 装不上

- Arch 用 `yay -S miyu`（预编译）或 `miyu-git`（源码）。依赖：`chafa ripgrep alsa-lib`。
- 源码构建需要 Rust 1.89+；`cargo build --release` 后二进制在 `target/release/miyu`。

### 首次运行没有初始化？

`miyu init` 手动初始化；`miyu paths` 看路径。大多数命令会自动初始化，但 `paths`、shell hook、`import` 等例外。

### 想换数据目录

```bash
MIYU_HOME=/path/to/miyu-data miyu ...
```

设置后运行时目录会用哈希隔离；旧 XDG 布局不会自动迁移。

### daemon 启动失败 / 端口被占

```bash
miyu daemon status
miyu daemon logs -n 200
```

- 默认 Web 端口 8300 被占时会自动换随机端口（仅默认端口场景）。
- 旧版本 daemon 占用数据时会由新二进制自动重启；手动 `miyu daemon restart`。
- QQ 反向 WS 端口与 WebUI 端口默认共用 8300，可单独设 `platforms.qq.reverse_ws_port`。

### daemon 一直占着数据库

导入前必须先 `miyu daemon stop`。其他共享数据操作（reset/pop/models 等）会自动走 IPC，不需要手动停。

## 配置与模型

### 想用自己的 API key

`miyu config` → 供应商/模型：

1. 新增供应商，填 base_url、protocol、api_key（支持 `$env:VAR`）。
2. 激活文本模型（Tab 切换）。
3. 需要识图就配多模态模型。

### 提示词改不动？

默认 Miyu 人格（`system-prompt.md`）内置在二进制里且故意不可热改。正确做法：新建自己的 persona，或编辑用户目录里的 `system-prompt.md` 覆盖默认。

### `miyu variant` / 模型切换没反应？

- 切换作用于当前会话，且“下一轮生效”。
- `default` 表示恢复跟随全局模型池。
- 单模型时 `variant` 不能切；多模型时用 `miyu models` 先选模型。

### 保存配置后报错

- `miyu config validate` 看具体项。
- 常见：`compact_force_ratio` 小于 `trim_at_ratio`；provider id 重复；QQ 端口为 0；记忆参数越界；`active_provider_models` 空数组（会被 normalize 回内置模型）。

## 对话与上下文

### `/reset`、`/reset-memory`、`/reset-all-memory`、`/wipe` 区别

| 命令 | 作用 |
|---|---|
| `/clear` | 只清屏幕 |
| `/reset` | 清当前会话历史/上下文 |
| `/reset-memory` | 清本会话记下的记忆（会话历史保留） |
| `/reset-all-memory` | 清当前人格全部记忆（会话历史保留） |
| `/wipe` | 全抹：历史 + 记忆 + 群聊上下文与产物 |

### 回复很慢 / token 消耗高

- 看 `cache/logs/cache-usage.*.jsonl` 的 `cache_read`。
- 长会话首次会慢；保持 daemon 常驻可复用前缀缓存。
- DeepSeek 官方等“尽力而为”缓存可尝试 `cache.keepalive_seconds=20`（按请求次数计费的网关不要开）。
- 网络搜索、深度研究、搜图都是 token 大户；不需要的功能可在插件页关。

### 上下文快满了

- 默认溢出策略 compact：自动把旧轮压缩成摘要。
- 终端 `/compact` 手动压缩，`/pop` 手动把旧轮移出。
- 旧内容可用 `search_evicted_context` 找回。

### 回复被取消/排队消息不见了

- 回复中按 `/` 输入的内容会排队，不是丢了。
- `Ctrl+C` 第一下只清空输入框；空输入时才中断。
- daemon 远程模式退出前端，任务继续；重进 REPL 可看到。

## 网络与插件

### 没配搜索 key，能搜索吗？

能。回退链：Exa 免 key MCP → DuckDuckGo 爬虫 → Yahoo → 360 → 搜狗。每日 Exa 额度有限，触发 429 会冷却并自动回退。

### 搜图没有结果 / 全部失败

- 下载阶段是 fail-fast，搜索阶段单源失败不影响。
- 安全搜图开启时，百度/360 需要视觉审核可用；审核不完整 fail-closed。
- 检查 `plugins.web_images.source_mode`、`max_download_mb`、超时。

### 生图用不了

`image_generation` 默认关闭。配置 OpenAI 兼容或 RightCode 的 base_url + api_keys，再打开插件。

### 天气不准/位置不对

- 默认 Open-Meteo；空 location 走 wttr.in 自动定位。
- 中文地名有别名表；重名按人口/行政等级选。要精确可给 `country_code` 或英文名。

## QQ

### QQ 没反应 / 连不上

- 确认 `platforms.qq.enabled` 和 token。
- 默认路径 `/onebot/v11/ws`；NapCat 端反向 WS 填 `ws://<Miyu机器>:8300/onebot/v11/ws`。
- 空 token 只允许本机回环地址；跨机器必须配 token。
- 看 `miyu daemon logs` 里的 `miyu::qq` 日志（默认 INFO）。

### 群里 Miyu 不理人

- 群聊必须 @机器人、回复机器人、或命中 `trigger_keywords`。
- real_context 默认 5% 概率主动判断，没到阈值就装死；管理员/白名单直触发更积极。
- 游客限流 2 条 / 600 秒；超了会静默丢弃或提示“太频繁”。

### 群管理工具失败

- 禁言单位是**秒**，不是分钟。
- 普通成员操作要 AI 二次确认；`/stop` 等命令只有管理员能用。
- NapCat 踢人报 `status=failed retcode=100` 可能是成员已退群，Miyu 会复查。

### QQ 长回复变图片失败

- 需要 `/usr/share/miyu/fonts/` 的 Noto CJK 字体；缺失时自动回退纯文本。
- 输入超 20000 字符、单页超像素/PNG 预算会失败并保留原文。

## WebUI

### 打不开 / 只显示登录页

- `miyu web --bind 127.0.0.1` 只本机；手机访问要 0.0.0.0 并保证防火墙放行。
- 设了密码就登录；忘记密码可以删 `state/web-passwords` 后重启（谨慎）。
- 默认端口冲突会自动换端口，注意终端打印的实际 URL。

### 网页一直转圈 / SSE 断线

- 断线不会取消回合；刷新后用 `Last-Event-ID` 补事件。
- 事件缓冲 4096 条，掉太久会要求 resync。
- 取消回合点停止按钮。

## 数据与备份

### 想备份

`miyu export`，详见 [12-备份迁移与更新](12-备份迁移与更新.md)。

### 导入失败

- 先停 daemon。
- 归档由更高版本导出会拒绝（防止新库导入旧程序）。
- 用 `--force` 会先备份当前安装。

### 更新默认知识库失败

- 需要 `git`；网络问题可重试。
- 校验失败不会替换现有默认库。
- 状态 24 小时才检查一次远程。

## 诊断

```bash
miyu --debug ...
MIYU_LOG=debug miyu daemon restart
miyu daemon logs -n 500
miyu daemon logs request      # 看出网请求
miyu paths                    # 看文件位置
```

诊断开关（不打开零开销）：

```bash
MIYU_IMAGE_TRACE=1   # → ~/.miyu/cache/logs/image-trace.log   图片网格与传输画布
MIYU_TAIL_TRACE=1    # → ~/.miyu/cache/logs/tail-trace.log    活动区每次重绘的滚动序列
```
