# 04 · 命令参考

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

所有命令都支持中英双语帮助（语言由 `MIYU_LANG` 或配置决定）。`miyu -h` 看总览，`miyu <命令> -h` 看子命令。

## 1. 根命令

```text
miyu [选项] [消息]... [命令]
```

| 参数 | 说明 |
|---|---|
| `--debug` | 写详细诊断日志到日志目录 |
| `--stdout` | 纯文本输出：无颜色、无 TUI，适合管道 |
| `--session <名/编号/id>` | 本次命令使用指定会话，不改变全局当前会话 |
| `-c, --continue` | 一次性消息发进终端集成会话（与 --session 互斥） |
| `MESSAGE...` | 直接发送的消息；省略则按 default_mode 进入 REPL 或显示模式说明 |

## 2. 命令清单

### 对话与模式

| 命令 | 说明 |
|---|---|
| `ask [消息...]` | 一次性聊天，默认临时会话 |
| `normal` | 普通模式 REPL（Miyu 人格 + 全能力） |
| `dev` | 开发模式 REPL（极简编码形态） |
| `tool-call [工具名] [参数JSON]` | 工具桥：`--stdin`、`--args-file`、`--list`、`--describe` |

### 初始化与配置

| 命令 | 说明 |
|---|---|
| `init` | 创建默认配置和状态文件 |
| `paths` | 显示配置、数据、缓存路径 |
| `config [validate|paths]` | 无参数打开配置 TUI；validate 校验；paths 显示配置路径 |
| `reload` | 重载配置（daemon 忙时自动重试） |
| `models [目标]` | 切换终端集成会话模型：列表序号 / `provider/model` / 裸名 / `default` |
| `list-models` | 列出可用模型 |
| `variant [档位]` | 切换终端会话模型的思考档位（无参数进入交互选择） |

### 终端集成

| 命令 | 说明 |
|---|---|
| `fish-init` / `bash-init` / `zsh-init` | 安装对应 shell 的自然语言集成 |
| `remove-shell-hook` | 安全删除已安装的 Miyu shell hook |
| `history [-l N] [--raw] [--no-thinking]` | 显示会话历史（默认 20 条） |
| `reset` | 清除终端集成会话上下文 |
| `reset-memory` | 清空当前人格长期记忆 |
| `pop [N]` | 把最旧 N 轮移出活跃上下文（无参数弹多选） |

### 数据管理

| 命令 | 说明 |
|---|---|
| `kb` | 知识库管理（见下） |
| `memory` | 记忆管理（见下） |
| `skills` | 技能管理（见下） |
| `update-default-kb` | 更新 Miyu 默认知识库（Shorin Wiki） |
| `wipe [--yes]` | 抹掉所有会话历史、记忆、群聊上下文及产物（危险） |
| `export [输出] [--all --index --platforms --no-secrets --dry-run --force]` | 导出便携归档 |
| `import 归档 [--force]` | 导入归档（导入前必须先停 daemon） |

### 服务与网页

| 命令 | 说明 |
|---|---|
| `web [--port P] [--bind ADDR] [-p [密码]] [--password-file 路径]` | 打开/启动 WebUI |
| `daemon [--port P] [start|stop|restart|status|logs]` | 管理统一后台服务 |
| `daemon logs [-n N] [request]` | 看日志；`request` 录制出网 LLM 请求 |

### 隐藏的内部命令（不需要手敲）

`__daemon`、`__alarm-worker`、`__tool`、`__renderer-worker`：由 Miyu 自己 spawn 子进程时使用。

## 3. `miyu kb` 子命令

| 子命令 | 说明 |
|---|---|
| `add 路径 [-r]` | 添加文件/目录到知识库（目录默认递归，-r 仅为兼容） |
| `list` | 列出知识库文件 |
| `search 查询 [-l N]` | 语义/关键词搜索 |
| `find 查询 [-l N]` | 按文件名找 |
| `read 文件 [--start N] [--lines N]` | 读知识库文件 |
| `remove 文件` | 删除文件 |
| `reindex` | 重建索引 |
| `stats` | 统计信息 |
| `embed reindex [--quiet]` | 重建 embedding 向量索引（需先配 embedding） |

## 4. `miyu memory` 子命令

| 子命令 | 说明 |
|---|---|
| `stats` | 记忆统计 |
| `reset [--include-skills]` | 清空记忆（可选连技能一起） |
| `search 查询 [-l N] [--forgotten]` | 搜索记忆（--forgotten 包含已遗忘） |
| `remember 内容 [-s source]` | 手动记一条事实（默认 source=manual） |

## 6. REPL 斜杠命令速查

见 [03-使用方式](03-使用方式.md)。完整清单：`/help /exit /new /session /rename /delete /workspace /models /persona /variant /usage /config /undo /pop /compact /history /clear /reset /reset-memory /wipe`。

## 7. QQ 平台斜杠命令

前缀默认 `/`（可配置为 1–32 个无空白字符）：

| 命令 | 权限 | 说明 |
|---|---|---|
| `/reset` | 管理员 | 清当前会话；带 `all` 参数语义由执行层处理 |
| `/wipe` | 管理员 | 两次确认：先提示，再回复 `confirm` |
| `/reset-memory` | 管理员 | 清记忆，需 `confirm` 确认 |
| `/stop` | 管理员 | 取消当前回合，保留历史 |
| `/models [参数]` | Everyone 或 AdminOnly（可配） | 查/切会话模型 |
| `/回复处理 ...` | 管理员 | 状态/阈值/模式/恢复默认（reply_processor 插件命令） |

命令边界严格：`/ reset`、`/resetting`、`/modelsx` 都不算命令。

## 8. 环境变量

| 变量 | 作用 |
|---|---|
| `MIYU_HOME` | 覆盖数据根目录（默认 `~/.miyu`） |
| `MIYU_LANG` | 临时覆盖界面语言：auto/en/zh |
| `MIYU_LOG` | 日志级别：off/error/warn/info/debug/trace |
| `MIYU_LOG_REQUESTS=1` | 开启完整请求录制（含请求体） |
| `MIYU_DEFAULT_KB_DIR` | 覆盖默认知识库来源目录 |
| `MIYU_DIRECT` | 非 0 时 REPL 走直连模式，不依赖 daemon |
| `MIYU_DAEMON_READY_TIMEOUT_SECS` | CLI 拉起 daemon 时的就绪等待秒数（默认 8）；daemon 启动本身不等 MCP 列举，正常无需调整 |
| `MIYU_EXA_MCP_ENDPOINT` | 覆盖 Exa 免 key MCP 端点 |
| `MIYU_SESSION` | tool-call/内部调用指定会话 |
