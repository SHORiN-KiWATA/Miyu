# 磁盘空间不足怎么清理

「磁盘空间不足」是 macOS 最常见的问题之一。按下面的顺序安全清理。

## 1. 先看空间去哪了

- 系统设置 → 通用 → 存储空间，查看各分类占用。
- 命令行版：`du -sh ~/Library/Caches ~/Downloads ~/Movies` 等逐个看。

## 2. 安全清理项

```zsh
# Homebrew 旧版本与缓存
brew cleanup

# 用户缓存（安全删除）
rm -rf ~/Library/Caches/*

# 系统日志
sudo rm -rf /private/var/log/asl/*.asl

# 废纸篓
rm -rf ~/.Trash/*
```

## 3. 大块头重灾区

- **Xcode**：`~/Library/Developer/Xcode/DerivedData`（编译缓存，可整个删）、`~/Library/Developer/CoreSimulator`（模拟器缓存，用 `xcrun simctl delete unavailable` 清不可用设备）。
- **iOS 备份**：`~/Library/Application Support/MobileSync/Backup` 里的旧备份。
- **Time Machine 本地快照**：`tmutil listlocalsnapshots /` 查看，`tmutil deletelocalsnapshots <日期>` 删除（快照用于「本地时间机器」，删了不影响正常 Time Machine 备份）。
- **微信/QQ 聊天记录与缓存**：应用内清理，或删除 `~/Library/Containers/com.tencent.xinWeChat` 下的旧缓存目录。
- **Docker**：`docker system prune -a` 清理镜像与构建缓存。
- **node_modules**：项目目录下 `find . -name node_modules -type d -prune -exec rm -rf {} +`（慎用，确认是旧项目）。
- **下载目录**：`~/Downloads` 里积压的 dmg/pkg。

## 4. 检查「系统数据」占用

系统设置 → 通用 → 存储空间里的「系统数据」很大时，多半是缓存和快照，按上面的方法清理后会自动缩小。

## 注意事项

- 不要手动删除 `/System`、`/Library` 下的文件，会造成系统损坏。
- 删除前先确认文件归属，不确定就先留着。
