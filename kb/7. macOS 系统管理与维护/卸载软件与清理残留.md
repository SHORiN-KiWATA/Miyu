# 卸载软件与清理残留

## 从 App Store 安装的 App

把应用从「启动台」或「应用程序」文件夹拖到废纸篓，或长按图标点 ×。

## 从网上下载的 .app

1. 把 `/Applications/xxx.app`（或 `~/Applications`）拖进废纸篓；
2. 清理残留配置（App 的配置通常在这里）：
   - `~/Library/Application Support/<App名>`
   - `~/Library/Preferences/<bundle-id>.plist`
   - `~/Library/Caches/<App名>`
   - `~/Library/Logs/<App名>`
3. 清空废纸篓。

用 `grep -r "<App名>" ~/Library` 不好用，推荐直接按名字找上面几个目录。

## Homebrew 安装的软件

```zsh
brew uninstall 包名          # 命令行工具
brew uninstall --cask 包名   # GUI 应用
```

## 彻底卸载

想清理得干净，可以用第三方工具（如 AppCleaner），或手动对照上面的残留目录删。

## 注意事项

- 不要直接删除 `/Applications` 下正在运行的 App 文件，先退出应用。
- 删除配置目录前可以先备份：`cp -R "~/Library/Application Support/xxx" ~/Desktop/xxx-backup`。
- 不确定是哪个 App 的目录时，用 `plutil -p <目录>/Contents/Info.plist 2>/dev/null | grep CFBundleName` 确认。
