# 安全与隐私设置

## 基础安全设置

系统设置 → 隐私与安全性：

- **锁定屏幕**：设置快捷锁屏 `Cmd + Ctrl + Q`，开启「需要密码」。
- **FileVault**（磁盘加密）：开启后整盘加密，换机/送修前必须记住恢复密钥或登录密码。
- **查找我的 Mac**：系统设置 → Apple ID → 查找 → 打开「查找我的 Mac」，丢电脑可以定位/抹除。
- **防火墙**：系统设置 → 网络 → 防火墙 → 打开；「隐身模式」可让本机不响应 ping。
- **自动更新**：保持系统与 App 更新开启（或定期手动更新）。

## 隐私权限自查

系统设置 → 隐私与安全性，逐项检查：

- 屏幕录制 / 辅助功能 / 输入监控：只给信任的软件；
- 完整磁盘访问：给备份/终端类工具即可，不认识的 App 别给；
- 文件与文件夹：按需授予。

## 安全习惯

1. 从官网/App Store 下载软件，不点来路不明的 dmg；
2. 打开下载的 App 前右键 → 打开，确认开发者信息；
3. 不把管理员密码给任何「清理工具」（系统本来就不需要清理软件）；
4. 浏览器装广告拦截（如 AdGuard、uBlock Origin）；
5. 开启两步验证（Apple ID、GitHub、常用账号）。

## 终端安全

- 不随便执行 `curl xxx | sudo sh` 类命令（看不到脚本内容）；
- `sudo` 后注意命令是否合理（`rm -rf`、`chmod 777` 都是高危操作）；
- 私钥（`~/.ssh/id_*`）不要发给任何人、不要传网盘。

## 常见问题

- **App 提示「来自互联网」**：正常，首次打开确认来源可信即可。
- **忘记 FileVault 恢复密钥**：登录进系统后可以在系统设置里重新生成；否则数据无法恢复。
- **需要找密码**：钥匙串访问（`钥匙串访问.app`）里查看已保存密码（需登录密码）。
