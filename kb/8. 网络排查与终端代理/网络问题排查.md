# 网络问题排查

macOS 上网络连不上/很慢时的排查步骤。

## 1. 基础检查

```zsh
ping -c 4 223.5.5.5        # 测外网连通（阿里 DNS）
ping -c 4 www.apple.com    # 测域名解析 + 连通
curl -sI --max-time 5 https://www.apple.com | head -1   # 测 HTTPS
```

- 都通 → 网络本身没问题，问题在具体应用。
- 都不通 → 检查 Wi-Fi/网线/路由器。

## 2. Wi-Fi 问题

- 系统设置 → Wi-Fi → 详情 → 「忘记此网络」后重新连接。
- 关闭再开启 Wi-Fi，或直接重启路由器。
- 2.4G/5G 频段问题：部分设备只支持 2.4G，确认路由器没隐藏 5G。

## 3. DNS 问题

网页打不开但 ping IP 通 → DNS 问题：

```zsh
sudo dscacheutil -flushcache   # 刷新 DNS 缓存
sudo killall -HUP mDNSResponder  # 重启 mDNS 服务
```

把 DNS 改成公共 DNS：系统设置 → 网络 → Wi-Fi → 详细信息 → DNS，加 `223.5.5.5`（阿里）和 `1.1.1.1`（Cloudflare）。

## 4. 代理问题

- 开了代理软件但全局流量不通：先关掉代理软件测试；通了就是代理配置问题，见「终端网络代理」。
- 系统代理残留：系统设置 → 网络 → 详细信息 → 代理，确认没残留无效代理。

## 5. 端口占用

某服务起不来、提示端口被占：

```zsh
lsof -i :4096        # 谁占用了 4096 端口
kill -9 <PID>        # 结束占用进程
```

## 6. 高级排查

```zsh
# 查看路由
netstat -rn | head -20
# 查看当前连接
netstat -an | grep ESTABLISHED | head -20
# 抓包（需要管理员）
sudo tcpdump -i en0 -n port 443
```

## 7. 重启大法

网络问题久查不决时，按顺序试：重启 Wi-Fi → 重启路由器 → 重启 Mac。
