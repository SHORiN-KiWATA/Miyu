# 电池与能耗管理

MacBook 电池相关的日常维护和问题。

## 查看电池健康

- 按住 `Option` 点菜单栏电池图标：显示「正常 / 需要维修」和循环计数。
- 系统设置 → 电池 → 电池健康（可开关「优化电池充电」）。
- 命令行：

```zsh
system_profiler SPPowerDataType | grep -E "Cycle|Condition|Maximum"
```

## 能耗排查

- 「活动监视器」→「能耗」标签：看哪些 App 耗电最多。
- 命令行：`top -o power`（按能耗排序）或 `ps -A -o %cpu,comm | sort -rn | head`。
- 菜单栏点电池图标看「使用电池」时的主要耗电 App。

## 省电技巧

1. 系统设置 → 电池 → 打开「低电量模式」（按需）；
2. 系统设置 → 显示器 → 自动调节亮度；
3. 关闭不需要的后台 App（菜单栏图标多的那些）；
4. 蓝牙不用时关掉；
5. 避免在高温环境使用（电池损耗最快的是高温 + 满电存放）。

## 充电管理

- 打开「优化电池充电」：日常插电使用时会自动把充电上限控制在 80% 左右，延长电池寿命。
- 长期插电当台式机用：建议始终开启优化充电，或用 `sudo pmset -a` 相关命令管理充电阈值（部分机型支持）。

## 命令行电源管理

```zsh
pmset -g batt            # 电池状态
pmset -g assertions      # 哪些 App 在阻止睡眠
sudo pmset -a sleep 15   # 无操作 15 分钟后睡眠
```

## 常见问题

- **待机掉电快**：检查 `pmset -g assertions` 里是否有 App 阻止睡眠（如浏览器持续播放、下载工具）；重启能解决大部分异常耗电。
- **电池显示「需要维修」**：循环次数到了或健康度下降，属正常老化；先尝试「校准」：充满 → 用到自动关机 → 再充满（新版系统此方法效果有限）。
- **插电不充电**：温度过高或优化充电在起作用（会显示「暂停于 80%」），拔插一次电源可临时绕过。
