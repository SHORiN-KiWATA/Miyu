# macOS 常用快捷键速查

## 截图与录屏

| 快捷键 | 作用 |
|---|---|
| `Cmd + Shift + 3` | 全屏截图 |
| `Cmd + Shift + 4` | 区域截图（空格键可切窗口截图） |
| `Cmd + Shift + 5` | 截图/录屏工具栏 |
| `Ctrl + Cmd + Shift + 4` | 区域截图到剪贴板 |

截图默认存桌面，按住 `Ctrl` 改为存剪贴板。

## 系统操作

| 快捷键 | 作用 |
|---|---|
| `Cmd + Space` | 聚焦搜索（Spotlight） |
| `Cmd + Tab` | 切换应用 |
| `Cmd + Q` | 退出当前应用 |
| `Cmd + W` | 关闭当前窗口 |
| `Cmd + M` | 最小化窗口 |
| `Cmd + H` | 隐藏当前应用 |
| `Cmd + Option + Esc` | 强制退出应用 |
| `Cmd + Ctrl + Q` | 锁定屏幕 |
| `Ctrl + 上箭头` | 调度中心（任务视图） |
| `Cmd + ,` | 打开当前应用偏好设置 |

## 文字编辑

| 快捷键 | 作用 |
|---|---|
| `Cmd + C / V / X / Z` | 复制/粘贴/剪切/撤销 |
| `Cmd + Shift + Z` | 重做 |
| `Cmd + 左/右箭头` | 光标移到行首/行尾 |
| `Cmd + 上/下箭头` | 移到文档开头/结尾 |
| `Option + 左/右箭头` | 按词移动光标 |
| `Ctrl + K` | 删除到行尾 |
| `Ctrl + U` | 删除到行首 |

## Finder

| 快捷键 | 作用 |
|---|---|
| `Cmd + Shift + .` | 显示/隐藏隐藏文件 |
| `Cmd + Shift + G` | 跳转到文件夹（输路径） |
| `Cmd + Up` | 返回上级目录 |
| `Cmd + Down` | 进入选中文件夹 |
| `Space` | 快速预览（选中文件后按） |
| `Cmd + N` | 新建窗口 |
| `Cmd + Shift + N` | 新建文件夹 |
| `Cmd + Delete` | 移到废纸篓 |
| `Cmd + Option + V` | 移动（剪切后粘贴） |

## 其他

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Cmd + Space` | 打开 emoji 面板 |
| `Cmd + Shift + 4 后按空格` | 窗口截图 |
| `Fn + E` | emoji 面板（部分键盘） |
| `Option + 点按菜单栏图标` | 部分 App 显示更多选项 |

## 自定义

系统设置 → 键盘 → 键盘快捷键 可以修改几乎全部系统快捷键；第三方工具（如 Karabiner-Elements）可做更底层按键映射。
