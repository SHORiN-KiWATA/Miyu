# 鸣潮·属性与声骸一览

## 属性（元素）体系

《鸣潮》的角色与声骸具有以下属性之一，属性之间通常不构成相克关系，而是通过「共鸣」与技能机制相互配合：

| 属性 | 英文 | 说明 |
|---|---|---|
| 湮灭 | Havoc | 破坏性力量，高爆发 |
| 气动 | Aero | 风系，机动与范围 |
| 导电 | Electro | 雷系，连锁与速度 |
| 热熔 | Fusion | 火系，持续灼烧 |
| 冷凝 | Glacio | 冰系，控制与冻结 |
| 衍射 | Spectro | 光系，净化与增益 |

## 声骸品质

声骸按稀有度分为不同品质（常见、稀有、史诗、传说等），品质越高，基础属性与可提升上限越高。高品质声骸（尤其是传说级）是后期养成的核心目标。

## 常见声骸来源

- 野外残响（普通怪）掉落低品质声骸。
- 精英怪 / 首领级残响掉落高品质声骸。
- 副本与特定活动可获取特定系列声骸。
