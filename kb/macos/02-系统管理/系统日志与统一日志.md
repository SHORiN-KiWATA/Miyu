# 系统日志与统一日志

macOS 用统一日志（unified logging）记录系统与 App 日志，`log` 命令是主要入口。

## 基本用法

```zsh
log show --last 1h                 # 最近 1 小时全部日志
log show --last 10m --predicate 'eventMessage CONTAINS "error"'   # 过滤错误
log stream --level debug           # 实时滚动日志
log show --last 1h --info          # 含 info 级别（默认不含）
```

## 按进程过滤

```zsh
log show --last 30m --predicate 'process == "kernel"'      # 内核日志
log show --last 30m --predicate 'processImagePath CONTAINS "Finder"'
log show --last 5m --predicate 'subsystem CONTAINS "com.apple.wifi"'
```

## 崩溃报告

- 图形界面：控制台 App（`open -a Console`）→ 崩溃报告。
- 命令行：`ls ~/Library/Logs/DiagnosticReports/` 看 `.ips` 文件。
- 内核 panic：`/Library/Logs/DiagnosticReports/` 或 `log show --predicate 'eventMessage CONTAINS "panic"'`。

## 查看启动过程

```zsh
log show --last 5m --predicate 'eventMessage CONTAINS "boot"' 
```

## 常见用途

- App 闪退：看 Console 里对应进程的崩溃报告，定位崩溃线程。
- 网络问题：过滤 wifi / network 子系统。
- 装完驱动/服务不生效：看对应 daemon 的日志。

## 清理日志

日志一般由系统自动滚动，不用手动清。磁盘紧张时可删旧 DiagnosticReports（只影响历史崩溃记录）。

注意：`log show` 全量查询很慢，尽量用 `--last 时间` 或 `--start/--end` 缩小范围。
