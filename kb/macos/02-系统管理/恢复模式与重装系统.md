# 恢复模式、重装系统与启动键

Mac 开机进恢复模式、重装系统、重置时的常用操作。

## 启动键（Apple Silicon）

开机按住电源键不放，直到出现「正在载入启动选项」再松手。

| 操作 | 按键 |
|---|---|
| 恢复模式 | 长按电源键 |
| 选择启动磁盘 | 长按电源键后选卷 |
| 安全模式 | 开机后长按电源键，选卷时长按 Shift |

## 启动键（Intel Mac）

开机立刻按住对应键，看到标志再松：

| 操作 | 按键 |
|---|---|
| 恢复模式 | Cmd + R |
| 网络恢复 | Option + Cmd + R |
| 启动磁盘选择 | Option |
| 安全模式 | Shift |
| 单用户模式 | Cmd + S（老系统） |
| 重置 NVRAM | Option + Cmd + P + R |

## 恢复模式里能干啥

- **磁盘工具**：急救、修复、抹掉。
- **重新安装 macOS**：装系统，一般不用先抹盘，覆盖安装保留数据。
- **终端**：菜单栏 → 实用工具 → 终端，可跑命令。
- **启动安全性实用工具**：Apple Silicon 上改启动策略（降低安全性、允许外部启动）。

## 重装系统

1. 进恢复模式 → 「重新安装 macOS」。
2. 选目标盘（系统卷，不要选 Data 卷）。
3. 等下载安装，Apple Silicon 会自动配好卷结构。

想干净重装：先「磁盘工具」抹掉整个容器（选 APFS 容器 → 抹掉），再装。

## 重置相关

- 退出 Apple ID：系统设置 → 你的名字 → 退出。
- 抹掉 Mac（Apple Silicon）：恢复模式 → 磁盘工具抹盘后，重新安装；或「系统设置 → 通用 → 传输或还原 → 抹掉所有内容和设置」。

## 排障

- 进不去恢复模式：确认机器通电、键盘没问题；Apple Silicon 长按电源键要按住不放。
- 装到一半断网：换个网络或插网线（转接头）。
- 提示磁盘被锁：恢复模式里用「启动安全性实用工具」把策略调低，或解锁磁盘。
