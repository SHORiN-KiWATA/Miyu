# 查看系统信息与诊断

收集 macOS 系统信息的方法，排障时先问这些。

## 基本版本信息

```zsh
sw_vers
# ProductName: macOS
# ProductVersion: 15.5       ← 系统版本
# BuildVersion: 24F74        ← 构建号
```

macOS 版本命名：14 Sonoma、15 Sequoia、26 Tahoe（2025 年起大版本号跳到了 26）。

## 硬件信息

```zsh
system_profiler SPHardwareDataType
# Model Name: MacBook Air
# Chip: Apple M2          ← 芯片型号
# Memory: 16 GB
```

只看芯片和内存：

```zsh
sysctl -n machdep.cpu.brand_string   # Intel 芯片型号
sysctl -n hw.memsize                 # 内存字节数（除以 1073741824 得 GB）
```

## 磁盘

```zsh
df -h /                    # 根分区剩余空间
diskutil list              # 所有磁盘/分区
diskutil info disk0 | grep -E "Name|Size"   # 具体磁盘
```

## 系统负载

```zsh
top -l 1 | head -15        # CPU/内存概况
vm_stat                     # 内存统计
ps aux | sort -rk 3 | head # 按 CPU 排序的进程
```

「活动监视器」App 是图形化版，看 CPU/内存/能耗/磁盘都很方便。

## 系统日志

```zsh
log show --last 1h --predicate 'process == "xxx"'   # 某进程最近 1 小时日志
log show --last 10m --style compact                 # 最近 10 分钟日志
log stream --predicate 'eventMessage CONTAINS "error"'   # 实时过滤日志
```

## 开机启动项

```zsh
# 用户 LaunchAgents
ls ~/Library/LaunchAgents/
# 系统 LaunchDaemons/Agents
ls /Library/LaunchAgents/ /Library/LaunchDaemons/
```

详见「开机自启与 LaunchAgent」。

## 崩溃报告

- 系统报告：「应用程序」→ 实用工具 → 控制台，左侧「崩溃报告」。
- 命令行：`ls ~/Library/Logs/DiagnosticReports/ | tail` 查看最近的崩溃日志。
