# 系统清理与存储空间

Mac 空间不够时的排查和清理思路。

## 先看空间被谁占了

系统设置 → 通用 → 储存空间，能按「系统数据、文稿、App、照片」分类看。

命令行：

```zsh
df -h                    # 磁盘整体占用
du -sh ~/Library/Caches  # 缓存大小
du -sh ~/Downloads       # 下载目录
```

## 常见大头

| 位置 | 说明 |
|---|---|
| `~/Library/Caches` | 各种 App 缓存，可删 |
| `~/Library/Application Support` | App 数据，**别乱删** |
| `~/Library/Logs` | 日志，可删 |
| `~/Library/Developer` | Xcode 缓存/派生数据，可删 |
| `/private/var/folders` | 系统临时/缓存，别手动删 |
| 本地快照 | `tmutil listlocalsnapshots /` 查看 |

## 清理动作

```zsh
# 缓存（会重新生成，安全）
rm -rf ~/Library/Caches/*
# 下载/废纸篓
rm -rf ~/.Trash/*
# 找大文件
find ~ -size +500M -exec ls -lh {} \; 2>/dev/null | awk '{print $9, $5}'
```

## Homebrew 清理

```zsh
brew cleanup -s          # 清理旧版本
brew autoremove          # 删孤儿依赖
```

## 系统更新残留

`/Library/Updates`、`~/Library/Updates` 里可能有下载完的安装包，空间紧张可删（更新会重新下载）。

## 别踩的坑

- 别删 `/System` 和 `/usr` 下的东西，SIP 保护 + 乱删会出问题。
- `~/Library/Application Support` 里的文件删了会让 App 丢配置。
- 别用各种「清理大师」，容易误删，macOS 自带管理够用。

## 终极方案

- 时间机器备份后删除旧备份。
- 卸载不用的 App（连带清理残留见「卸载软件与清理残留」）。
- 真不够用就外接硬盘，把照片/素材移出去。
