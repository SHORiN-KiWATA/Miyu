# 常见报错与解决

收集 macOS 日常使用中常见的报错和解决办法。

## 「无法打开，因为无法验证开发者」

从网上下载的 App 第一次打开会提示。解决办法（任选）：

```zsh
# 1. 右键 App → 打开 → 再点「打开」
# 2. 或清除隔离属性：
xattr -dr com.apple.quarantine "/Applications/xxx.app"
```

## 「xxx 已损坏，无法打开。你应该将它移到废纸篓」

通常是下载不完整或签名问题。先重新下载；仍不行（且来源可信）再清除隔离属性：

```zsh
xattr -dr com.apple.quarantine "/Applications/xxx.app"
```

## xcrun: error: invalid active developer path

安装/更新 Xcode 后命令行工具失效：

```zsh
xcode-select --install        # 安装命令行工具
# 或指定 Xcode 路径：
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

## command not found

1. 命令没安装 → 用 `brew install <命令名>` 安装；
2. 已安装但找不到 → PATH 问题。检查：`echo $PATH`、`which <命令>`；
3. Homebrew 装了但终端找不到 → 确认 `~/.zprofile` 里有 `eval "$(/opt/homebrew/bin/brew shellenv)"`。

## zsh: permission denied

脚本没有执行权限：

```zsh
chmod +x 脚本文件
```

## Operation not permitted（没有权限访问某目录）

macOS 的 TCC 权限机制：系统设置 → 隐私与安全性 → 完整磁盘访问权限 / 文件与文件夹，把对应终端 App 打开。

## Resource busy / 文件被占用

```zsh
lsof 文件路径      # 看哪个进程占用
kill <PID>        # 结束进程后再操作
```

## 磁盘已满但删不掉

- 先看「磁盘空间不足怎么清理」。
- 删除文件后空间没释放：检查废纸篓、Time Machine 本地快照（`tmutil listlocalsnapshots /`）。

## 系统提示「更新」卡住

- 重启再试；`sudo softwareupdate --reset-ignored` 可重置忽略的更新。
- 存储空间不足也会导致更新失败，先清理空间。
