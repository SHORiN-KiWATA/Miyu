# 进程管理与信号

排查和控制系统里跑的进程。

## 查看进程

```zsh
ps aux                       # 全部进程
ps aux | grep 关键词          # 找指定进程
ps -o pid,ppid,%cpu,%mem,command -p <pid>   # 看单个进程
pgrep -fl 名字                # 按名字找 PID
```

## 结束进程

```zsh
kill <pid>                   # 温和结束（SIGTERM）
kill -9 <pid>                # 强制结束（SIGKILL），慎用
pkill -f "命令行关键词"       # 按名字/命令行批量结束
```

先 `kill`，等几秒没反应再 `kill -9`。强制杀可能丢数据。

## 后台与前台

```zsh
command &                    # 后台运行
jobs                         # 列出当前 shell 的后台任务
fg %1                        # 拉回前台
bg %1                        # 放到后台继续
nohup command &              # 退出终端后仍运行
disown                       # 从当前 shell 摘除，关终端不杀
```

## 孤儿进程

终端关掉后残留的进程，父进程变 1（launchd）。用 `ps -o pid,ppid,command` 看，PPID 为 1 且你不认识的基本就是孤儿，可直接 kill。

## 优先级

```zsh
nice -n 10 command           # 低优先级启动
renice -n 10 <pid>           # 调整已运行进程优先级（负值需 root）
```

## 实用组合

```zsh
ps aux | sort -k3 -rn | head    # 最吃 CPU 的
ps aux | sort -k4 -rn | head    # 最吃内存的
lsof -iTCP:8300                 # 谁占了 8300 端口
```
