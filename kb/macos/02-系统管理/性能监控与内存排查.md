# 性能监控与内存压力排查

Mac 变卡先别重启，用这几招定位到底谁在吃资源。

## 实时看 CPU/内存

```zsh
top -o cpu -n 10        # 按 CPU 排序，看前 10
top -o mem -n 10        # 按内存排序
ps aux -r | head        # 直接看最吃 CPU 的进程
ps aux -m | head        # 最吃内存的进程
```

`top` 里按 `o` 可换排序字段，`q` 退出。

## 内存压力

```zsh
memory_pressure -Q      # 系统级内存压力摘要
vm_stat                 # 详细内存统计（页）
```

看 `memory_pressure -Q` 输出的「free percentage」：长期低于 50% 说明内存紧张；交换（swap）大量增长也是信号。

```zsh
sysctl vm.swapusage     # 看交换文件用量
```

## 找出异常进程

- 某个进程 CPU 常年 100%：`sample <pid> 5` 采样几秒看它在干嘛。
- 某个进程内存只涨不降：多半是泄漏，杀掉重开；反复泄漏就换替代品。
- 孤儿进程：终端关掉后残留的后台进程，`ps -o pid,ppid,command` 看 PPID 为 1 的就是被"收养"的孤儿。

## 活动监视器

GUI 版：启动台 → 活动监视器，或 `open -a "Activity Monitor"`。看「内存」标签页底部的「内存压力」图，绿色=健康，黄/红=吃紧。

## 一键查看系统概览

```zsh
system_profiler SPHardwareDataType   # 芯片/内存
uptime                                # 开机时长 + 负载
```

load average 三个数分别代表 1/5/15 分钟平均负载；Apple Silicon 上一般和核心数对比看，持续远超核心数就是过载。

## 排查顺序建议

1. 先 `top -o cpu` 看有没有进程异常吃 CPU。
2. `memory_pressure -Q` 看内存压力。
3. 异常进程 `sample` 采样定位。
4. 长期不关机的 Mac 隔一阵重启一次，释放缓存和泄漏。
