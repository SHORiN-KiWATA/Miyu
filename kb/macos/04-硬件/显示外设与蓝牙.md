# 显示、外设与蓝牙

Mac 接显示器、键盘鼠标、蓝牙设备的常用操作和排障。

## 外接显示器

- 直接插 Type-C / HDMI（需转接头）；Apple Silicon 原生支持多台外接（具体数量看机型）。
- 分辨率/缩放：系统设置 → 显示器 → 分辨率。
- 排列：系统设置 → 显示器 → 排列，拖拽调整相对位置。
- 找不到外接：换线/换口，确认显示器切对输入源；重启显示器电源。

## 常见显示问题

- 字体发虚：确认用的原生分辨率，缩放别拉太高。
- 外接屏闪烁：换高质量线（认准支持对应协议的线），关掉「自动调节亮度」。
- 刷新率：系统设置 → 显示器 → 刷新率，ProMotion 机型可选 120Hz。

## 蓝牙设备

```zsh
# 查看蓝牙状态与已连接设备
system_profiler SPBluetoothDataType
```

- 连不上：先「系统设置 → 蓝牙」里删掉设备重新配对。
- 键盘/鼠标卡顿：2.4G 干扰多，离 USB3 设备、路由器远点；或插线用。
- 耳机断连：关掉「自动切换」和「优化电池充电」试试。

## 鼠标键盘

- 鼠标滚轮方向：系统设置 → 鼠标 → 自然滚动（关掉就是"Windows 方向"）。
- 键位改：系统设置 → 键盘 → 键盘快捷键；第三方用 Karabiner-Elements 改键。
- 快捷键不生效：检查是不是被输入法/其它 App 抢了（常见于输入法切换）。

## 妙控板手势

系统设置 → 触控板里可调：轻点点击、三指拖移（辅助功能里开）、四指切换空间等。

## 排障顺序

1. 换线换口排除硬件。
2. 删设备重新配对。
3. 重启相关服务或重启机器。
4. 查 `system_profiler` 看设备是否被系统识别。
