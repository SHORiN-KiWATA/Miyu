# 终端网络代理

终端里的命令默认**不走**系统代理（系统设置里开的代理只对 GUI 应用生效），需要手动设置环境变量。

## 临时设置（当前终端会话）

```zsh
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890
export all_proxy=socks5://127.0.0.1:7890
```

端口以你的代理软件为准（Clash 系常用 7890，Surge 常用 6152，其他软件看设置页）。

## 持久设置

写进 `~/.zshrc` 或 `~/.zprofile`：

```zsh
# 代理开关
alias proxy='export https_proxy=http://127.0.0.1:7890 http_proxy=http://127.0.0.1:7890 all_proxy=socks5://127.0.0.1:7890'
alias unproxy='unset https_proxy http_proxy all_proxy'
```

使用时 `proxy` 开启、`unproxy` 关闭。

## 验证是否生效

```zsh
curl -s --max-time 5 https://www.google.com -o /dev/null -w "%{http_code}\n"
# 200 说明代理生效
```

## 只给某个命令用

```zsh
https_proxy=http://127.0.0.1:7890 git clone https://github.com/xxx/yyy.git
```

## 常见问题

- **git 走代理**：`git config --global http.proxy http://127.0.0.1:7890`。
- **ssh 走代理**：`~/.ssh/config` 里加 `ProxyCommand nc -X 5 -x 127.0.0.1:7890 %h %p`。
- **代理软件开了但终端不通**：确认代理软件的「允许局域网连接 / Allow LAN」开启（部分软件默认只监听 127.0.0.1 以外的流量规则）。
- **科学上网相关**：只讨论技术配置，不提供任何机场或订阅渠道。
