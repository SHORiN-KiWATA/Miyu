# App 安装与来源

macOS 安装软件的主要渠道与安全判断。

## 来源分级

| 来源 | 安全性 | 说明 |
|---|---|---|
| App Store | 高 | 苹果审核，自动更新 |
| 官网 dmg/pkg | 高 | 只从软件官网下载 |
| Homebrew | 高 | 开源，依赖可控 |
| 第三方下载站 | 低 | 可能捆绑广告/恶意软件，尽量避免 |

## 各方式安装

### App Store

打开 App Store 搜索安装，更新走系统自动更新。

### 官网 dmg

1. 下载 dmg → 双击挂载 → 把 .app 拖进「应用程序」；
2. 首次打开若提示「无法验证开发者」，见「常见报错与解决」。

### Homebrew

```zsh
brew install --cask 包名    # GUI 应用
brew search 包名            # 先搜索确认包名
```

### pkg 安装包

双击按向导安装（多为驱动/命令行工具，会写入系统目录），建议安装时看清每一步。

## 验证下载文件

```zsh
# 校验 sha256（官网会给出期望值）
shasum -a 256 下载的文件.dmg

# 查看签名信息
codesign -dv /Applications/xxx.app 2>&1 | head -5
spctl -a -vv /Applications/xxx.app   # Gatekeeper 评估
```

## 判断 App 是否可信

1. 开发者名字是否与官网一致（系统设置 → 隐私与安全性里能看到）；
2. 安装后看看「活动监视器」里有没有奇怪进程；
3. 来路不明的「破解版/绿色版」App 是最常见的恶意软件来源。

## 常见问题

- **App Store 下载慢**：换网络/挂代理；「系统设置 → App Store → 自动更新」开着的话稍等。
- **dmg 挂载后没有 .app 而是 .pkg**：pkg 是安装向导，直接双击按提示装。
- **「已损坏」提示**：见「常见报错与解决」。
