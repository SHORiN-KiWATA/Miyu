# 输入法与中文输入问题

macOS 自带输入法一般够用，遇到问题先看这篇。

## 基本操作

- 切换输入法：`Ctrl + Space`（或 `Cmd + Space` 若被 Spotlight 占用则在设置里改）。
- 中英切换：`Caps Lock`（默认）或 `Ctrl + Space`（系统设置 → 键盘 → 输入法 可改）。
- 打开输入法列表：系统设置 → 键盘 → 文本输入 → 编辑。

## 添加/删除输入法

系统设置 → 键盘 → 文本输入 → 编辑 → `+` 添加「简体拼音」「简体五笔」等；选中后 `-` 删除。

## 常见问题

### 输入法切换不了

1. 确认输入法没被删：系统设置 → 键盘 → 文本输入 → 编辑；
2. 第三方输入法（搜狗/微信输入法等）冲突时，先删掉第三方只留系统输入法测试；
3. 重启「简体拼音」：删除后重新添加。

### 打不出中文/候选框不显示

1. 检查是否在英文输入法状态；
2. 重启当前 App（有些老 App 对输入法支持差）；
3. 重置输入法缓存：删除 `~/Library/Caches/com.apple.inputmethod.SCIM*` 后注销重登。

### 输入法卡顿/高占用

- 检查「活动监视器」里 `SCIM` / `中文输入` 相关进程的 CPU；
- 第三方输入法导致时考虑换回系统自带；
- 更新系统版本通常能修复输入法 bug。

### 中英标点混乱

系统设置 → 键盘 → 文本输入 → 编辑 → 「全角/半角」选项；输入法菜单里也有「中文/英文标点」切换（`Shift + Space` 或快捷键自定义）。

## 第三方输入法

常用：搜狗输入法、微信输入法、Rime（鼠须管）。安装后需要在系统设置里授予「输入监控」权限才能正常使用。
