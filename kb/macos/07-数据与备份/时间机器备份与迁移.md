# 时间机器备份与迁移

## 开启时间机器

1. 外接硬盘（或 NAS/网络卷）格式化为 APFS 或 HFS+；
2. 系统设置 → 通用 → 时间机器 → 添加备份磁盘；
3. 自动备份开启后每小时增量备份一次。

## 命令行操作

```zsh
tmutil startbackup --auto     # 立即开始备份
tmutil listbackups            # 列出所有备份
tmutil listlocalsnapshots /   # 列出本地快照（未外接磁盘时的临时备份）
tmutil deletelocalsnapshots 2026-08-01-083000   # 删除指定本地快照
tmutil latestbackup           # 最新备份路径
tmutil destinationinfo        # 备份目标信息
```

## 恢复

- 整机恢复：开机按住 `Cmd + R` 进恢复模式 → 从时间机器恢复。
- 单文件恢复：进入「时间机器」界面（`Cmd + Shift + 5` 旁边的时钟图标，或菜单栏时间机器图标）→ 时间线找文件 → 恢复。

## 迁移助理

换新电脑：新 Mac 首次启动时选「从 Mac 迁移」，或随时用「应用程序 → 实用工具 → 迁移助理」。传输方式支持时间机器、另一台 Mac、外接磁盘。

## 常见问题

- **本地快照占满磁盘**：见「磁盘空间不足怎么清理」。
- **备份失败**：检查磁盘格式（APFS 最佳）、磁盘剩余空间、`tmutil destinationinfo` 显示的状态。
- **时间机器提示「无法完成备份」**：删除该磁盘的备份记录重新添加：`sudo tmutil removedestination <ID>`。
