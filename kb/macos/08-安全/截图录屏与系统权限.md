# 截图录屏与系统权限

macOS 的隐私权限机制（TCC）是「权限不足」类问题的高发区。

## 截图与录屏

- 快捷键：`Cmd + Shift + 3/4/5`（详见「macOS 常用快捷键速查」）。
- 命令行截图：`screencapture -x 输出.png`；录屏：`screencapture -V 5 输出.mov`（5 秒）。

## 权限位置

系统设置 → 隐私与安全性：

| 权限 | 影响 |
|---|---|
| 屏幕录制 | 录屏、截取其他 App 窗口内容 |
| 辅助功能 | 控制其他 App（快捷键类工具、菜单栏工具常用） |
| 输入监控 | 读取键盘输入（输入法类工具） |
| 完整磁盘访问 | 读取受保护目录（终端、备份工具常用） |
| 文件与文件夹 | 访问「桌面/文稿/下载」等目录 |
| 通知 | 发通知（含菜单栏提示） |
| 蓝牙 | 连接蓝牙设备 |

## 常见问题

- **录屏黑屏/录不到内容**：屏幕录制权限没开，或开了没重启对应 App。
- **App 已经授权还是不生效**：把权限关掉再打开（先移除再重新添加），然后完全退出 App 重开。
- **终端执行命令报 Operation not permitted**：给终端开「完整磁盘访问权限」或「文件与文件夹」权限。
- **改了权限不生效**：修改权限后需要退出并重新启动对应 App，部分系统级权限需要重启 Mac。

## 命令行管理

```zsh
# 查看 TCC 数据库（需完整磁盘访问权限）
sqlite3 ~/Library/Application\ Support/com.apple.TCC/TCC.db "SELECT service, client FROM access;"
```

不建议手动改 TCC 数据库，容易出问题；用系统设置改更稳妥。
