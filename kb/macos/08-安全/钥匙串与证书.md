# 钥匙串与证书

钥匙串（Keychain）是 macOS 的凭据保险箱，管着密码、证书、密钥。

## 钥匙串是什么

- 登录钥匙串：`~/Library/Keychains/login.keychain-db`，存你的密码、Wi-Fi、网站凭据。
- 系统钥匙串：系统级凭据（Wi-Fi、VPN、企业证书），需要时系统自动询问。
- iCloud 钥匙串：跨设备同步，启用了就在「系统设置 → 你的名字 → iCloud → 密码与钥匙串」。

## 查看与管理

```zsh
security list-keychains          # 列出钥匙串
security find-internet-password -s github.com   # 查某网站的密码（会提示解锁）
security find-generic-password -l 名称
```

图形界面：启动台 → 钥匙串访问（Keychain Access）。

## 常见问题

- App 反复要密码/证书：钥匙串访问里找到对应条目删掉重来。
- 「更新钥匙串设置」弹窗：通常是 App 想存新凭据，允许即可。
- 忘了 WiFi 密码：钥匙串访问搜 WiFi 名，勾选「显示密码」。
- 证书过期：钥匙串访问 → 我的证书，看有效期；企业证书过期会让 VPN/邮件失灵。

## 证书安装与信任

- 双击 `.cer/.pem` 导入钥匙串。
- 自签证书要手动信任：钥匙串访问 → 双击证书 → 信任 → 始终信任。
- 命令行导入：`sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain cert.pem`

## 命令行常用

```zsh
security find-certificate -c 名称      # 查找证书
security delete-certificate -c 名称    # 删除证书
security dump-keychain                 # 导出（敏感，慎用）
```

## 排障顺序

1. 确认 App 有权限访问对应钥匙串条目（系统设置 → 隐私与安全性）。
2. 删掉异常条目重新授权。
3. 证书问题先看有效期，再看信任设置。
