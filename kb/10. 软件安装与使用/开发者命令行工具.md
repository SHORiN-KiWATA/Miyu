# 开发者命令行工具

## 安装

```zsh
xcode-select --install
```

会弹出安装「Command Line Tools」（clang、git、make 等）。没有完整 Xcode 也能用。

## 常用工具

| 工具 | 作用 |
|---|---|
| `clang` | C/C++ 编译器 |
| `git` | 版本控制 |
| `make` / `cmake` | 构建 |
| `xcrun` | 调用 Xcode 工具链（签名、打包） |
| `sips` | 图片尺寸/格式转换 |
| `iconutil` | 图标打包（.iconset → .icns） |
| `hdiutil` | 磁盘镜像（dmg）制作与挂载 |
| `codesign` / `spctl` | 签名与 Gatekeeper 评估 |
| `plutil` / `PlistBuddy` | plist 文件读写 |
| `lsof` / `netstat` | 端口与网络排查 |

## 开发环境配置

```zsh
# 确认工具链
clang --version
git --version

# Python（系统自带 3.9+，装包用 pip3）
python3 --version

# Node（建议用 nvm 安装管理版本）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | zsh

# Rust（GQY 开发需要）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustc --version
cargo --version
```

## GQY 开发工具

GQY 是 Rust 项目，开发时需要以下工具：

### Rust 工具链
```zsh
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 安装 nightly 工具链（某些功能需要）
rustup install nightly
rustup default stable

# 安装交叉编译工具
rustup target add aarch64-unknown-linux-gnu
```

### Cargo 命令
```zsh
# 编译检查
cargo check

# 运行测试
cargo test

# 代码检查
cargo clippy -- -W warnings

# 构建项目
cargo build

# 构建发布版本
cargo build --release --locked
```

### 交叉编译
```zsh
# 安装 cross 工具
cargo install cross

# 交叉编译 aarch64 Linux
cross build --release --target aarch64-unknown-linux-gnu
```

## 常见问题

- **xcrun: error: invalid active developer path**：重新 `xcode-select --install`，或 `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`（装了完整 Xcode 时）。
- **clang: command not found**：没装命令行工具，先 `xcode-select --install`。
- **pip3 装包报权限错误**：用 `pip3 install --user 包名` 或创建虚拟环境 `python3 -m venv .venv`。
- **git 提交中文乱码**：`git config --global core.quotepath false`。
- **cargo build 失败**：检查 Rust 工具链版本，GQY 需要 Rust 1.97.1+。
- **cross 编译失败**：检查 Cross.toml 配置，确保依赖正确。
